# التكامل مع النواة الرقمية

## الحالة الحالية: وضع تجريبي
لا يوجد مفتاح نظام لواجهة `core-api` في وقت البناء، فالتكامل يعمل بوضع `demo`: جدول `athar.core_demo_staff` فيه ثلاثة سجلات موسومة `[تجريبي]` برقم وظيفي `DEMO-0001..3`، وتظهر لافتة تحذير في الواجهة. **لا يوجد اتصال فعلي بالنواة، ولم يُختبر الاتصال بها.**

## وضع API
محوّل `coreLookupStaff` في `supabase/functions/athar-api/index.ts` مكتوب وفق `docs/api.md` في مستودع النواة (قراءة فقط، ترويسة `x-system-key`). ليفعّل:
1. من إعدادات النواة والتكامل أنشئ مفتاح نظام بنطاق `staff:read` على الأقل.
2. اضبط أسرار الدالة: `CORE_API_URL` (https://kbhovmnvqzgihhyibqkq.supabase.co/functions/v1/core-api) و`CORE_API_KEY`.
3. من الإدارة ← الإعدادات والتكامل: «التحويل إلى وضع API».

تنبيهات صريحة:
- المحوّل يطابق الحقل `employee_no` في استجابة `/v1/staff`. إن كانت النواة لا تُرجعه فيلزم إضافة نقطة بحث أو تعديل المطابقة. لم يُجرَّب لعدم توفر المفتاح.
- عند تعذر الاتصال يُرفض التفعيل برسالة واضحة، وتُسجَّل الحالة في `core_integration` وتظهر في لوحة الإدارة (آخر فحص، النتيجة، آخر نجاح). لا تُعرض بيانات مخزّنة باعتبارها محدّثة.
- لا يخزّن أثر بيانات المنسوب الأساسية إلا الاسم المعروض لازماً للعرض، مع المعرّف المرجعي.

## الطلاب
ربط الطالب بسجل المتعلمين (`students.core_student_id`) غير مفعّل بعد؛ الحقل جاهز. يسجّل الطالب بياناته داخل أثر ويتحقق منها المختصون.
