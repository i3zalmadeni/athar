# النشر

1. طبّق الترحيلات بالترتيب على مشروع Supabase.
2. فعّل Pages (المصدر: GitHub Actions)؛ يُنشر `site/` تلقائياً عند الدفع إلى main.
3. لا حاجة لإنشاء مدير يدوياً: مدير النواة يحصل على دور المدير عند أول دخول له. (`athar.bootstrap_admin` احتياطي فقط.)
4. ضع شعار المدرسة المعتمد في `logoUrl` داخل `site/assets/config.js` (فارغ حالياً).
5. أنشئ روابط التعبئة من لوحة الإدارة > روابط التعبئة.
