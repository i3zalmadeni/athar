# أثر – النظام الرقمي لمدرسة لبيد بن ربيعة المتوسطة

بوابات دخول مستقلة للمنسوبين والطلاب وأولياء الأمور، بقاعدة بيانات تشغيلية مستقلة (مخطط `athar` في Supabase) ومرتبط بالنواة الرقمية عبر طبقة تكامل منفصلة.

الحالة: قيد البناء. المنجز: مخطط قاعدة البيانات (`supabase/migrations/0001`). ملف الدوال `0002` جاهز ولم يُطبَّق بعد.
