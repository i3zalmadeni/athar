# أثر

نظام قياس الأثر وإدارة الاستبانات لمتوسطة لبيد بن ربيعة ضمن منظومة النواة الرقمية.

- الفئات: المتعلم، المعلم، الهيئة الإدارية، الجهة المشرفة، ولي الأمر. لكل فئة استبانة أو أكثر (حتى 10 أسئلة، بمحاور العملية التربوية والبيئة المدرسية والقيادة).
- المعلم والهيئة الإدارية: دخول بحساب النواة (`site/login.html`) وتظهر استباناتهم في «مكتبي الإلكتروني» حسب فئتهم في النواة.
- المتعلم وولي الأمر والجهة المشرفة: بلا حسابات؛ رابط الاستبانة `site/form.html?t=...`، والاسم والبريد والجوال اختيارية.
- بعد الإغلاق تُنشأ دراسة (نتائج وتحليل وتوصيات)، تعتمدها الإدارة فتظهر للمنسوبين المشاركين (`site/study.html`).
- الواجهة: HTML/JS ثابت (RTL، Tajawal) على GitHub Pages. البيانات: مخطط `athar` في مشروع Supabase المشترك، عبر دوال RPC فقط.

الوثائق في `docs/`. الاختبار: `node tests/smoke.mjs` (يحتاج Playwright).
