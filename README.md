# أثر

النظام الرقمي لمتوسطة لبيد بن ربيعة ضمن منظومة النواة الرقمية.

- المنسوبون: دخول بحساب النواة الرقمية الموحد (`site/login.html`).
- الطلاب وأولياء الأمور: بلا حسابات؛ يفتحون رابط تعبئة تصدره المدرسة (`site/form.html?t=...`).
- الواجهة: HTML/JS ثابت (RTL، Tajawal) على GitHub Pages. البيانات: مخطط `athar` في مشروع Supabase المشترك، ولا يُوصل إليه إلا عبر دوال RPC.

الوثائق في `docs/`. الاختبار: `node tests/smoke.mjs` (يحتاج Playwright).
